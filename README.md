# Portfólio — Gabriel Augusto

Primeira versão do meu portfólio pessoal, desenvolvida com HTML e CSS.

O objetivo deste site é apresentar minha evolução como estudante de Ciência da Computação, minhas principais habilidades e alguns projetos desenvolvidos durante meus estudos.

## Tecnologias

- HTML5
- CSS3
- Design responsivo

## Seções

- Início
- Sobre mim
- Habilidades
- Projetos
- Contato

## Como executar

Não é necessário instalar nenhuma dependência.

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
